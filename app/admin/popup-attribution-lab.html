Verification pipeline

1 · AssignmentDeterministic visitor hash chooses POPUP or HOLDOUT.
2 · Signed sessionServer-issued HMAC session token is stored for the Shopify pixel bridge.
3 · CheckoutShopify pixel supplies checkout token + signed popup session. A bad popup token never blocks checkout.
4 · Order truthOnly Shopify HMAC-verified order webhooks turn the checkout link into a verified purchase and revenue record.
5 · ProfitPending Profit OS source parity.Revenue is available before margin/profit is promoted to truth.
